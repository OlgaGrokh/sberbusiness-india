# СберБизнес — «Продукты, услуги и сервисы» + одностраничник «Поиск поставщика в Индии»

Статичный HTML-прототип, воссозданный по фото экрана. Сборка и сервер не нужны.

## Как открыть
1. Скачать репозиторий: **Code → Download ZIP** и распаковать.
2. Открыть `index.html` двойным кликом в браузере.

Ссылки напрямую на одностраничник: `index.html#india` (текущий макет), `index.html#india-new` (с правками).

## Что внутри
- **Страница «Продукты, услуги и сервисы»**: шапка, левое меню, «Рекомендуем для вашей компании», «Отраслевые бизнес-решения», «Включено в ваш пакет услуг», «Витрина продуктов СберБизнес».
- **Одностраничник** (модальное окно поверх страницы) — открывается по клику на любой «Поиск поставщика в Индии» / «Бизнес мосты с Индией» / «Услуги»:
  - «Текущий макет» — как в дизайне (IndiaMall);
  - «С правками» — текст из комментария (1–4 скролл + вопросы).
- **Карточки из комментариев** в стиле сайта: алерт с кнопкой «Оставить заявку», гост-таб «+ Бизнес с Индией», карточка «Акции и новинки», экран успеха с аккордеоном, блок «Рекомендации».
- **Комментарии** — метки как в Pixso; в каждой есть кнопка, которая показывает правку.

Панель управления — справа внизу.

## Шрифт
Используется **SB Sans Interface**. Если он установлен в системе, подхватится сам.
Иначе положите файлы в папку `fonts/` с именами
`SBSansInterface-Regular`, `SBSansInterface-Semibold`, `SBSansInterface-Bold` (`.woff2` или `.ttf`).
Без шрифта показывается системный (на нём текст чуть шире).

## Что приближённо
- 3D-иллюстрации (шар с ₹/₽, телефон, карта, контейнер, кубы, здание, «коробка» в шапке одностраничника) заменены упрощёнными векторными. Чтобы поставить оригиналы, сохраните PNG в `img/` и замените вызовы `ILL.*` в `assets/app.js` на `<img src="img/...">`.
- Ответы на вопросы в текущем макете одностраничника на фото не видны — стоят заглушки.
- В «Ведение счёта» пункт «Внесение наличных — Пополняйте счёт через банкомат» восстановлен по фрагменту подписи.
- Опечатки из макета сохранены как есть: «Проверенна информация», «Моя бухглтерия Онлайн», «опертору».

## Файлы
- `index.html` — разметка
- `assets/style.css` — стили и цветовые токены (`:root`)
- `assets/app.js` — данные (меню, карточки, витрина, тексты одностраничника, комментарии) и логика
- `assets/illustrations.js` — векторные иллюстрации
